## stm32f4072_disc1_rtos
This project is educational project main purpose of which to get familiar with STM32F407 board and freeRTOS enviroment.

## Prerequisites

Currently assumes arch Linux environment.

### Requirements
    - arm-none-eabi-gcc
    - cmake >= 3.22
    - stlink

## Build instructions
Build project:
`./build.sh`

Flash project:
`./flash.sh`
